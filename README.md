## 🚀 Getting Started

### Prerequisites

Before running the programs, ensure that you have installed:

- Java Development Kit (JDK)
- A code editor such as Visual Studio Code, IntelliJ IDEA, or Eclipse

Verify your Java installation by running the following commands in your terminal:

```bash
java -version
javac -version
```

### How to Run a Java Program

1. Clone the repository:

   ```bash
   git clone https://github.com/ThakurAkanksha28/1024160019_UCS553_JAVA.git
   ```

2. Navigate to the repository directory:

   ```bash
   cd 1024160019_UCS553_JAVA
   ```

3. Open the required assignment folder and locate the Java source file.

4. Compile the program:

   ```bash
   javac FileName.java
   ```

5. Run the program:

   ```bash
   java ClassName
   ```

Replace `FileName` with the Java filename and `ClassName` with the name of the class containing the `main()` method. Do not include `.java` in the run command.
