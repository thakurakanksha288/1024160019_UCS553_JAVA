# List of Experiments (UNIT-1) UCS553 — Week 3

## Q1 — Online Food Delivery System
Packages: `food.model`, `food.service`, `food.utility`, `food.main`

Compile:
    javac -d out (Get-ChildItem -Recurse -Filter *.java food) 

Run:
    java -cp out food.main.Main

## Q2 — Smart Library Resource Management System
Packages: `library.model`, `library.service`, `library.util`, `library.main`

Compile:
    javac -d out (Get-ChildItem -Recurse -Filter *.java library)

Run:
    java -cp out library.main.Main

Both were compiled and run successfully during development (JDK 21).
